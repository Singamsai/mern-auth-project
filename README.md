# SecureAuth – MERN Authentication Platform

A full-stack authentication web application built using the MERN stack (MongoDB, Express.js, React.js, Node.js).
The application provides secure user authentication, protected routes, Google OAuth login, profile management, and persistent user sessions.

## 🚀 Live Demo

https://mern-auth-3tsk.onrender.com/

## 📌 Features

- User Signup & Login
- JWT Authentication & Authorization
- Secure Password Hashing using bcryptjs
- Protected Routes
- Persistent User Sessions
- Google Authentication using Firebase
- Profile Image Upload
- Responsive UI
- Redux State Management
- RESTful API Architecture
- MongoDB Atlas Integration
- Full Deployment on Render
